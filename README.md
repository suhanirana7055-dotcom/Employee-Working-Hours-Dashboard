# Employee Working Hours Dashboard

## 📌 Project Overview

This Excel project analyzes employee working hours and active customer time using an interactive dashboard.

The dashboard helps understand employee-wise working hours and customer activity using Pivot Tables, charts, and data analysis.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Excel Dashboard

## 📊 Dashboard Features

- Employee-wise working hours analysis
- Active time with customers
- Comparison of employee performance
- Interactive charts
- Pivot Table-based analysis
- Dashboard visualization

## 📈 Key Analysis

The dashboard provides insights into:
- Total working hours of employees
- Active time spent with customers
- Employee-wise comparison
- Working hours visualization

## 🎯 Project Objective

The objective of this project is to practice Excel data analysis and dashboard creation using Pivot Tables and charts to generate meaningful business insights.
